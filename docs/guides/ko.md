# AgentSpace 사용 안내

[English](en.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md)

내 작업과 에이전트의 도움을 하나의 로컬 공간에서 관리합니다. 모델 계정 없이도 작성, 정리, 복구할 수 있습니다. 외부 에이전트는 명시적인 권한으로 자료를 읽고 검토 가능한 제안을 보냅니다.

## 공간 열기

새 로컬 폴더에 공간을 만들거나 기존 AgentSpace 공간을 엽니다. 현재 공간은 상단에 표시됩니다. 예제 공간은 따로 저장되며 합성 자료라는 표시가 있습니다.

앱과 데이터는 별개입니다. 앱을 옮겨도 데이터는 이동하지 않습니다. 사용할 위치에 앱을 둔 뒤 에이전트 구성을 생성하고, 실행 파일을 옮겼다면 다시 생성하세요.

첫 버전은 macOS Apple Silicon에서 검증했습니다. 로컬 빌드는 ad-hoc 서명을 사용하며 Developer ID 서명과 공증은 받지 않았습니다. 다른 운영체제는 검증된 배포 대상으로 주장하지 않습니다. 소스 개발에는 저장소에 지정된 Node 버전을 사용합니다.

## 작성과 연결

“작업 이어가기”에서 복구용 초안, 이 공간 인스턴스의 최근 자료 최대 10개, “최근 변경 보기”를 이용합니다. 전체 자료를 제한된 범위로 탐색하는 입구는 “라이브러리”이며 검색·필터·새 자료는 같은 스크롤 영역에 있습니다. 최근 위치에는 ID와 시간만 저장하며 본문을 복제하지 않습니다. 사용할 수 없는 항목은 최근 목록에서만 제거하고 일시 오류는 재시도할 수 있습니다. 복원한 새 인스턴스는 자체 최근 목록을 사용합니다.

“검토 상태”에서는 전체, 검토 전, 현재 버전 검토됨, 검토 후 변경됨을 선택합니다. 검토 전은 경고가 아닙니다. 상세 정보의 “버전 검토”는 현재 저장된 버전과 사람이 마지막으로 검토한 버전을 표시하며 미저장 초안과 구분합니다. 새로 확인한 저장된 현재 버전만 표시할 수 있습니다. 저장이나 제안 적용은 검토 또는 사실 인증이 아닙니다. 이후 새 버전은 “검토 후 변경됨”에서 찾을 수 있고 과거 출처는 고정된 내용을 유지합니다.

독립된 노트를 언제든 만드세요. 프로젝트는 관계로 자료를 묶습니다. 노트 하나가 여러 프로젝트에 속해도 같은 ID를 유지하며 자산도 여러 프로젝트에서 참조할 수 있습니다.

입력을 잠시 멈추면 자동 저장되며 즉시 저장할 수도 있습니다. 저장 완료는 현재 편집 세대가 영구 저장됐다는 뜻입니다. 복구용 초안 보관은 별도 상태입니다. 충돌하거나 실패하면 재시도, 초안, 내용 복사 경로를 이용하세요. 이후의 편집을 조용히 덮어쓰지 않습니다.

프로젝트는 본문 발췌, 이어서 작업할 참조, 직접 자산 참조, 페이지로 나눈 자료가 있는 개요로 열립니다. 각 구역의 버튼은 전체 본문 밖에 있습니다. “프로젝트 본문 편집”으로 작성하고 빈 프로젝트에서는 “프로젝트 목표 편집”을 선택하세요. 개수는 불러온 항목이나 기록된 참조이며 공간 전체의 총수가 아닙니다. 고정된 일과는 요구하지 않습니다.

출처 읽기에서 “현재 원문 편집”을 선택하면 저장·초안 보호를 거쳐 같은 내부 객체의 현재 버전을 엽니다. K1을 읽고 현재 K2를 수정해 저장하면 같은 ID의 K3가 되며 K1과 인용은 고정된 채 유지됩니다. 같은 객체의 기존 미저장 편집은 원래 편집기에 남고 기준 버전과 충돌이 표시됩니다. “읽기로 돌아가기”는 인용 버전과 이전 위치를 복원합니다. 현재 원문이 보관되었거나 사용할 수 없어도 읽을 수 있는 이력은 유지됩니다. 외부 원본 파일을 수정하는 작업은 아닙니다.

레코드는 텍스트, 유한한 숫자, 불리언, 날짜, 선택 값을 지원합니다. 필드 이름은 어떤 언어로든 쓸 수 있으며 이름을 바꿔도 안정적인 키를 유지합니다. 미설정, 빈 문자열, 0, false는 구분됩니다. 필드 정의를 재사용하면 값을 비운 새 레코드가 만들어집니다. 표는 같은 레코드의 제한된 뷰이며 별도의 전역 스키마가 아닙니다.

관계는 현재 객체와 특정 버전에 고정한 근거를 구분합니다. 원본이 바뀌어도 인용은 당시 버전을 가리킵니다. 사람의 검토 표시도 특정 버전에 속하며 저장이나 제안 적용만으로 사실의 정확성이 보장되지는 않습니다.

## 기존 폴더 가져오기

파일이나 폴더를 선택한 뒤 텍스트 사본, 프로젝트 묶음, 외부 참조를 미리 보고 확인합니다. knowledge, projects, HANDOFF, repos 인식은 선택 가능한 편의 프로필이며 필수 폴더 구조가 아닙니다.

유효한 UTF-8 Markdown과 일반 텍스트는 편집 가능한 사본으로 가져옵니다. 원본 파일은 바꾸지 않습니다. 저장소와 지원하지 않는 형식은 외부 참조로 명시적으로 선택할 수 있지만 내부 내용을 복사하거나 실행·동기화하지 않습니다. 지식을 가져와도 검토 완료로 자동 표시하지 않습니다.

스캔 범위, 건너뛴 이유, 잘림 표시를 확인하세요. 미리보기에 없는 자료를 검사했다고 주장하지 않습니다. 미리보기 이후 원본이 바뀌면 다시 검토해야 합니다. 항목별로 저장하므로 부분 실패 시 성공한 항목은 남습니다. 재시도는 원래 확정 버전을 찾고 이후 사람의 수정을 덮어쓰지 않습니다. 다른 원본 버전은 별도 사본이 됩니다.

프로젝트 묶음 선택은 새 사본에 적용됩니다. 이미 가져온 같은 원본 버전은 기존 객체와 현재 관계를 유지하며 이번 가져오기로 다시 분류하지 않습니다. 변경하려면 해당 객체를 열어 관계를 직접 편집하세요.

백그라운드 양방향 동기화는 없습니다. 재시작 후 명시적으로 이어가며, 복원한 공간의 이전 가져오기는 원본을 다시 선택하고 확인해야 합니다.

## 에이전트와 작업하기

설정에서 이름이 있는 접근 권한을 만듭니다. 전체 공간 또는 선택한 객체, 읽기와 제안 권한을 고릅니다. 읽기와 제안을 허용한 전체 공간 권한에만 새 노트·레코드 생성을 추가할 수 있습니다. 특정 객체에 한정된 권한으로는 새 객체를 만들 수 없습니다. 링크는 대상에 대한 접근 권한을 자동으로 넓히지 않습니다.

생성한 MCP 구성을 호스트에 복사하거나 [CLI](../AGENT_PROTOCOL.md)를 사용합니다. 토큰은 발급 시 한 번만 반환하며 DB에는 해시만 남습니다. 잃어버리면 권한을 취소하고 새로 발급하세요. 구성에는 인증 정보가 들어 있습니다.

에이전트는 모델 설명, 구조화된 필터, 리터럴 검색, 제한된 관계 탐색, 특정 버전 읽기를 작업에 맞게 조합합니다. 월간 회고는 가능한 작업의 예일 뿐 내장 워크플로가 아닙니다. 검색은 범위와 제한을 표시하며 의미상 완전한 검색을 보장하지 않습니다.

저장된 버전과 참조를 확인하고 복사할 수 있습니다. 저장하지 않은 내용은 초안입니다.

- **활동 → 실제 변경**: 다시 열어도 직접 저장과 제안 결정을 찾을 수 있습니다. 각 기록에는 시각, 실행자, 당시 버전 또는 원래 제안으로 가는 경로가 표시됩니다.
- **준비된 컨텍스트**: 도구 결과를 위해 준비한 참조와 범위를 확인합니다. 준비만으로 호스트 수신, 이해 또는 외부 작업 완료가 확인되지는 않습니다.
- **검토 → 처리 대기／처리됨**: 상태별 로드된 기록, 추가 로드 및 재시도를 이용합니다. 원래 차이, 이유 및 고정 출처를 확인할 수 있습니다. **적용 당시 버전 읽기**는 저장된 결과를 열고, 현재 원문은 별도 동작으로 엽니다. 출처에서 돌아오면 원래 제안 선택과 읽던 위치가 복원됩니다.

제안을 만들거나 거절해도 적용된 본문은 그대로 유지됩니다. 거절한 제안도 계속 확인할 수 있습니다.

제안에서 목적, 이유, 차이, 기준 버전, 근거를 살핍니다. 인용 당시 버전으로 출처를 연 뒤 검토로 돌아올 수 있습니다. 적용 전까지 정식 내용은 변하지 않습니다. 기준 버전이 바뀌면 양쪽 내용을 보존합니다. 원래 권한을 취소한 뒤에도 후보를 거절할 수 있습니다. 되돌리기는 이후 작업을 보호하며 이전 버전을 새 노트로 복사할 수도 있습니다.

적용 이유와 출처는 이력에 남습니다. 다른 허가된 에이전트가 원래 채팅이나 작업 키 없이 추적할 수 있습니다. 결과를 읽을 수 있다고 모든 근거를 읽을 수 있는 것은 아닙니다.

## 데이터 보존과 복구

보관은 활성 목록에서 제외하는 작업이며 ID나 이력을 삭제하지 않습니다. 프로젝트를 보관해도 노트와 공유 자산은 지워지지 않습니다. 외부 자산이 이동하면 이전 위치와 새 위치를 확인해 다시 연결합니다. 같은 ID와 이력을 유지합니다. 일반 되돌리기로 외부 위치 연결을 되돌릴 수는 없습니다. 이전 위치로 돌아가려면 그 위치를 명시적으로 다시 선택하세요.

| 방식            | 포함                                                         | 제외                                     |
| --------------- | ------------------------------------------------------------ | ---------------------------------------- |
| 전체 백업       | 일관된 DB, 보관 버전, 제안, 작업 영수증, 초안, 가져오기 이력 | 외부 파일과 코드 저장소의 실제 내용      |
| 읽기용 내보내기 | 보관 항목을 포함한 현재 내용, 필드, 관계, 출처 메타데이터    | 이전 본문, 제안, 영수증, 초안, 외부 파일 |

내보내기는 데이터 교환용이며 전체 이력 복원용이 아닙니다. 두 결과물 모두 원본 경로 같은 개인 메타데이터를 포함할 수 있습니다. 검증된 완료 결과를 기다리세요. 응답을 잃으면 결과는 알 수 없는 상태이므로 상태를 확인하거나 같은 작업을 재시도합니다.

백업은 새 위치에 복원합니다. 새 인스턴스 ID를 부여하고 복원본의 기존 에이전트 권한을 비활성화합니다. 원래 공간과 권한은 바뀌지 않으며 에이전트는 다시 연결해야 합니다. 다른 설치에 속한 초안은 확인한 뒤 현재 설치의 새 초안으로 복사할 수 있습니다. 원래 초안은 그대로 남습니다.

## 현재 범위

객체 전체는 1 MiB, 이력과 영수증을 포함한 DB는 512 MiB까지입니다. 가져오기는 깊이 12, 방문 항목 1,000개, 선택한 텍스트 50 MiB를 검사합니다. 맥락 도구에도 명시적인 개수와 바이트 제한이 있습니다. DB 한도에 도달해도 쓸 수 있는 위치로 백업·내보내기를 할 수 있습니다.

AgentSpace 자체는 데이터를 암호화하지 않습니다. 운영체제로 로컬 파일을 보호하세요. 외부 호스트가 모델 제공자와 도구 밖의 권한을 관리합니다. 클라우드 동기화, 팀 계정, 의미상 진위 판단, 임의 앱 실행, 완전한 스프레드시트 엔진은 이번 범위 밖입니다. 첫 공개 버전은 형식 2를 사용합니다. 지원하지 않는 개발 형식은 원본을 바꾸지 않고 거부합니다.
