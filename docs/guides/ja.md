# AgentSpace の使い方

[English](en.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md)

自分の作業とエージェントの支援を、一つのローカル空間にまとめます。モデルのアカウントがなくても執筆、整理、復元ができます。外部エージェントは明示した権限で読み取り、レビュー可能な提案を送ります。

## 空間を開く

新しいローカルフォルダーに空間を作成するか、既存の AgentSpace 空間を開きます。ヘッダーに現在の空間を表示します。サンプルは別の空間にあり、合成資料であることを明示しています。

アプリとデータは別です。アプリを移動してもデータは移動しません。アプリを使う場所に置いてから接続設定を生成し、実行ファイルを移動した場合は再生成してください。

初版の検証対象は macOS Apple Silicon です。ローカルビルドは ad-hoc 署名で、Developer ID 署名・公証は行っていません。他の OS を検証済みとはしていません。ソース開発にはリポジトリで指定した Node を使います。

## 書く、関連づける

「作業を再開」では復旧用下書き、この空間インスタンスの最近の資料（最大10件）、「最近の変更を見る」を利用できます。全体を範囲付きで探す入口は「ライブラリ」です。検索、条件、新規資料は一つのスクロール内にあります。最近の位置にはIDと時刻だけを保存し、本文を複製しません。利用不可の項目は最近の一覧から削除でき、一時エラーは再試行できます。復元後の新しいインスタンスは独自の一覧を使います。

「確認状態」は全件、未確認、現在の版を確認済み、確認後に変更ありを選べます。未確認は警告ではありません。詳細の「版の確認」は現在の保存済みの版と最後に人が確認した版を示し、未保存の下書きとは分けます。新しく確認した保存済みの現在版だけに印を付けられます。保存や提案の採用は確認済みや真実の保証を意味しません。後から版が進むと「確認後に変更あり」で見つかります。過去の出典は固定された内容のままです。

独立したノートをいつでも作れます。プロジェクトは関連で資料をまとめます。一つのノートを複数のプロジェクトに所属させても、同じ ID のままです。アセットも複数の作業で参照できます。

入力が止まると自動保存され、すぐ保存することもできます。「保存済み」は表示中の編集世代が永続化された状態です。復旧用下書きの保持とは区別します。競合・失敗時には再試行、下書き、コピーの方法を選べます。後から行った編集を無言で上書きしません。

プロジェクトは概要から開きます。本文の抜粋、引き継ぎ用の参照、直接のアセット参照、ページ分けした資料を表示し、各項目へのボタンを全文の外に置きます。「プロジェクト本文を編集」で記述でき、空のプロジェクトには「目標を編集」があります。件数は読み込み済みの資料や記録済みの参照で、空間全体の総数ではありません。固定した日課は求めません。

出典の閲覧画面で「現在の原文を編集」を選ぶと、保存・下書きの保護を経て同じ内部オブジェクトの現在版を開きます。K1を読み、現在のK2を編集して保存すると、同じIDのK3になります。K1と引用は固定されたままです。同じオブジェクトの未保存の編集は元のエディターに残り、基準版や競合を表示します。「閲覧に戻る」で引用版と呼び出し位置に戻れます。現在の原文がアーカイブ済み・利用不可でも、閲覧できる履歴を残します。外部の元ファイルを編集する操作ではありません。

レコードはテキスト、有限数値、真偽値、日付、選択肢に対応します。項目名は任意の言語で記述でき、名前を変えても項目キーを保持します。未設定、空文字、0、false は別の値です。項目定義の再利用では値を空にした新規レコードを作ります。表は同じレコードの範囲を限定した表示で、独立した全体共通スキーマではありません。

関連は現行オブジェクトと特定版の根拠を区別します。参照元を編集しても引用は当時の版を指します。人による確認済み印も特定版に対応し、保存や提案の採用だけで内容の正しさを保証しません。

## フォルダーを取り込む

ファイルまたはフォルダーを選び、コピー、プロジェクトのまとめ方、外部参照を確認して確定します。knowledge、projects、HANDOFF、repos の認識は任意の補助設定で、必須の保存形式ではありません。

有効な UTF-8 の Markdown・プレーンテキストを編集可能なコピーにします。元ファイルは変更しません。リポジトリや非対応形式は明示して外部参照にできますが、内容のコピー、実行、同期は行いません。知識を取り込んでも自動で確認済みにはしません。

走査範囲、除外理由、打ち切り表示を確認してください。表示していない資料を検査済みとはしません。プレビュー後に元ファイルが変わると再確認が必要です。項目ごとに保存するため、一部失敗でも成功分を保持します。再試行は元の確定版を再利用し、その後の人の修正を上書きしません。別の元ファイル版は別コピーになります。

まとめ方の指定は新しいコピーに適用します。取り込み済みの同じ元ファイル版は元のオブジェクトと現在の関連を再利用し、今回の指定で所属を変えません。変更する場合は、そのオブジェクトを開いて関連を明示的に編集してください。

バックグラウンドの双方向同期はありません。再起動後は明示的に再開します。復元した空間の古い取り込みでは、参照元を選び直して承認します。

## エージェントと作業する

設定で名前付きのアクセス許可を作り、空間全体か特定オブジェクトか、読み取り・提案の権限を選びます。新規ノート・レコードの作成を追加できるのは、読み取りと提案を許可した空間全体のアクセスだけです。特定オブジェクトの許可では新規作成できません。リンク先に権限は自動で広がりません。

生成した MCP 設定をホストへコピーするか、[CLI](../AGENT_PROTOCOL.md) を使います。トークンの返却は発行時の一度だけで、保存するのはハッシュです。紛失時は取り消して再発行してください。設定には認証情報が含まれます。

エージェントはモデル説明、絞り込み、リテラル検索、限定した関連探索、特定版の読み取りを組み合わせます。月次振り返りは一例で、内蔵ワークフローではありません。検索は範囲と制限を報告し、意味的な網羅性は保証しません。

保存済みの版を参照とともに確認・コピーできます。未保存の文章は下書きです。

- **アクティビティ → 実際の変更**：再起動後も本人の保存や提案への決定を確認できます。各記録には時刻、実行者、その時点の版または元の提案への入口があります。
- **準備したコンテキスト**：ツール結果用にまとめた参照と範囲を確認できます。準備だけでは、ホストへの到達、理解、外部作業の完了は確認できません。
- **レビュー → 未処理／処理済み**：状態ごとの読み込み済み記録、追加読み込み、再試行を利用できます。元の差分・理由・固定ソースを確認できます。**適用時の版を読む**で保存された結果を開き、現在の原文は別の操作で開きます。ソースから戻ると提案の選択と読む位置が復元されます。

提案の作成や却下では、適用済みの本文は変わりません。却下した提案も確認できます。

提案の目的、理由、差分、基準版、根拠を確認します。参照を引用時の版で開き、レビューへ戻れます。採用前は正式な内容が変わりません。基準版が変われば双方の内容を保持します。元の許可を取り消した後でも候補を却下できます。取り消しは後続の編集を保護し、旧版を新しいノートへコピーすることもできます。

採用理由と根拠は履歴に残ります。別の許可済みエージェントが、元のチャットや操作キーなしで参照できます。結果へのアクセスは根拠へのアクセスを意味しません。

## データを保つ

アーカイブは活動中の一覧から外す操作で、ID や履歴を削除しません。プロジェクトのアーカイブでノートや共有アセットを消しません。外部アセットが移動したら、元と新しい場所を確認して選び直します。同じ ID と履歴を保ちます。通常の取り消しでは外部の場所変更を戻しません。元の場所に戻す場合は、その場所を明示的に選び直してください。

| 方法                 | 含むもの                                                           | 含まないもの                                   |
| -------------------- | ------------------------------------------------------------------ | ---------------------------------------------- |
| 全体バックアップ     | 一貫したデータベース、保持版、提案、操作結果、下書き、取り込み履歴 | 外部ファイルやリポジトリの内容                 |
| 読み取り用の書き出し | アーカイブを含む現行内容、項目、関連、出所情報                     | 旧版本文、提案、操作結果、下書き、外部ファイル |

書き出しはデータ交換用で、全履歴の復元用ではありません。どちらにも元のパスなど個人情報が含まれ得ます。検証済みの完了結果を待ってください。応答を失ったら結果は不明です。状態確認か同じ操作の再試行を使います。

バックアップは新しい場所に復元します。新しいインスタンス ID を割り当て、復元先の旧アクセス許可を無効にします。元の空間と許可は変えません。エージェントは再接続が必要です。他のインストールの下書きは確認後、新しい下書きへ明示的にコピーでき、元の下書きは残ります。

## 現在の範囲

オブジェクト全体は 1 MiB、履歴・操作結果を含む DB は 512 MiB までです。取り込みは深さ 12、訪問 1,000 件、選択テキスト 50 MiB までを検査します。文脈取得にも明示した件数・バイト制限があります。DB 上限後も書き込み可能な出力先へのバックアップ・書き出しは利用できます。

AgentSpace 自体は暗号化しません。OS でファイルを保護してください。外部ホストがモデルサービスやツール外の権限を管理します。クラウド同期、チーム、意味的な真偽判定、任意アプリ実行、完全な表計算エンジンは対象外です。初の公開版は形式 2 です。非対応の開発形式は元ファイルを変えずに拒否します。
