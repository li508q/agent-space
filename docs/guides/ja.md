# AgentSpace の使い方

[English](en.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md)

AgentSpace は、文章、プロジェクトの資料、エージェントの提案を一つのローカルスペースで扱います。モデルのアカウントがなくても、読み書き、整理、復元ができます。

## スペースを作成・選択する

新しいローカルフォルダーを使う場合は**スペースを作成**、既存の AgentSpace フォルダーを使う場合は**スペースを開く**を選びます。**サンプルスペースを開く**では、自分の資料と別に保存されたサンプルを試せます。選択中のスペースはヘッダーに表示されます。

アプリとスペースは別です。アプリを移動してもデータは移動しません。使う場所にアプリを置いてからエージェントの接続設定を生成し、実行ファイルを移動したら設定を再生成してください。

**設定**で表示言語と文字サイズを選べます。言語を切り替えても、自分で書いたタイトル、本文、フィールド名は翻訳されません。

## 作業を再開する・資料を探す

**作業を再開**には、復旧用の下書き、このスペースのインスタンスで最近開いた資料（最大 10 件）、**最近の変更を見る**があります。最近の一覧は同じ資料への参照で、本文のコピーを保存しません。利用できない項目を一覧から削除しても、資料自体は削除されません。一時的なエラーは再試行できます。復元したインスタンスは独自の一覧を使います。

保存済みの資料は**ライブラリ**で閲覧、検索、絞り込みができます。作成する場合は**新しい資料**を選びます。最近の作業がなくても、資料が空とは限りません。件数やページ表示は確認した範囲を示すので、必要に応じてさらに読み込んでください。

## 既存の資料を取り込む

作業を再開、スペースメニュー、または絞り込みのない空のライブラリから、**既存の資料をインポート**を開きます。

1. ファイルかフォルダーを選びます。
2. プレビューで、本文のコピー、プロジェクトのまとめ方、外部参照、除外項目、走査範囲を確認します。
3. 確定し、項目ごとの結果を確認します。

有効な UTF-8 の Markdown とプレーンテキストは、出所情報を持つ編集可能な管理対象コピーになります。元ファイルは変更しません。リポジトリや他の形式は明示的に外部参照にできますが、内容のコピー、実行、同期は行いません。knowledge、projects、HANDOFF、repos の認識プロファイルは、分類を提案する任意の補助機能です。

打ち切られたプレビューは、表示された走査範囲だけを扱います。プレビュー後に元ファイルが変わった場合は、再確認してください。項目ごとに確定するため、一部失敗しても成功分は残ります。再試行や同じ元ファイル版の再取り込みは、元のオブジェクトを再利用し、その後の編集と現在の関連を保持します。分類の指定は新しいコピーに適用されます。再利用した資料の関連を変える場合は、明示的に編集してください。異なる元ファイル版は別のコピーになります。

バックグラウンドのファイル同期はありません。再起動後は未完了の取り込みを明示的に再開します。復元したスペースでは、古い取り込みの参照元を選び直して確認します。

## 書く・保存状態を確かめる

**新しい資料**から、ノート、プロジェクト、レコード、再利用するアセットを作成できます。ノートはプロジェクトに所属しなくても使えます。**詳細**でフィールドや関連を編集すると、同じノートやアセットを複数のプロジェクトから参照できます。

自分の編集は入力を少し止めると直接保存されます。**今すぐ保存**も使えます。エディター横の状態を確認してください。

- **保存済み**は、表示中の編集内容が現在の内容として保存された状態です。
- **復旧用の下書きを保存しました**は、復旧用の下書きが保持された状態です。本文の保存完了とは別です。
- **未保存**や**保存結果を確認中…**の場合は、エディターを開いたまま、表示された再試行で元の要求の結果を確認してください。

競合時は、編集中の内容と新しい保存済みの版を別に保持します。現在の原文を確認してから続け方を決めてください。下書きも保持できない場合は、閉じる前に**編集内容をコピー**で本文を別に保管できます。保持した下書きは「作業を再開」から開けます。下書きを再開するだけでは、正式な内容として保存されません。

レコードはテキスト、有限数値、真偽値、日付、選択肢を使えます。未設定（`null`）、空文字、`0`、`false` は別の値です。フィールドの名前を変えても識別情報を保ち、種類を変えると値は未設定になります。フィールド定義の再利用は、本文や関連をコピーせず、値が未設定の新しいレコードを作ります。レコード表は同じ資料の範囲を限定した表示で、選んだ参照レコードの定義を列に使います。

## プロジェクトの蓄積と出典を読む

プロジェクトの概要には、目標の抜粋、引き継ぎ用の参照、直接のアセット参照、ページ分けした資料があります。**プロジェクト本文を編集**で全文を書けます。空の場合は**目標を編集**を選びます。件数は読み込み済みの資料や記録済みの参照を示します。フィールドや引き継ぎ用のリンクは必要に応じて使え、固定した作業手順は求めません。

関連は**現在の版を参照**するか、**固定した版**を指します。引用元を後から編集しても、出典の参照は引用時の保存済みの版を保ちます。過去のプロジェクトに記録されたリンクと、現在のプロジェクト資料は別に表示され、過去の所属全体のスナップショットにはなりません。

出典の閲覧画面で**現在の原文を編集**を選ぶと、同じ管理対象オブジェクトの現在版を開きます。たとえば第 1 版を読みながら現在の第 2 版を編集して保存すると、同じオブジェクトの第 3 版になります。第 1 版と引用は変わりません。未保存の編集がすでにあれば、元のエディターに基準版や競合とともに残ります。**閲覧に戻る**で引用版と元の位置に戻れます。現在の原文がアーカイブ済み・利用不可でも、閲覧可能な履歴は残ります。編集するのは管理対象コピーであり、外部の元ファイルではありません。

## エージェントに渡す文脈を準備する

保存済みの文書か出典の閲覧画面で、**コンテキストを準備**を選びます。

1. 必要に応じて、Unicode コードポイントで最大 1,000 文字のタスクを書きます。
2. **重複しない保存済みの版への参照を最大 20 件**選びます。最初は起点の資料だけが選択されています。候補はその版の直接リンクと、起点がプロジェクトの場合は現在のアクティブなプロジェクト資料です。各グループをさらに読み込めます。
3. **説明と参照を確認**を開き、表示内容を確かめてから**説明と参照をコピー**します。

説明にはタスクと固定した参照が入り、起点のプロジェクトを選択している場合は最大 280 文字の目標の抜粋も含められます。選択を解除すると、そのタイトルと抜粋も除かれます。リンク先の本文を再帰的に取り込むことはありません。利用できない選択済みの版は再試行か選択解除が必要で、新しい版へ置き換えられません。

コピー完了は、文字列がクリップボードに入ったことを示します。アクセス権の作成や、エージェントの受信を意味しません。準備内容はスペースを開いている間のメモリに残り、設定や取り込みを往復しても保持されます。保存文書や再起動後に復旧できる下書きではありません。

## アクセス権を作成して接続する

文脈の準備から**エージェント接続を設定**を選ぶか、**設定**で同じ項目を開きます。

1. アクセス権の名前を付け、特定のオブジェクトかスペース全体を選び、読み取りと提案の権限を指定します。
2. 最初のページ外にある準備済みの資料も含めて確認します。既存の選択は保持され、**選択した資料を使用**で明示的に置き換えます。
3. **接続権限を作成**し、Codex の設定か stdio 起動用 JSON をコピーします。ホストの MCP 設定に追加して接続し直し、説明をエージェントに渡します。[プロトコルガイド](../AGENT_PROTOCOL.md)には CLI の使い方もあります。

説明は特定の版を固定しますが、オブジェクトのアクセス権は**今後の版を含む**読み取り可能な版を対象にします。新しいリンクやプロジェクト資料は、固定した選択対象に追加されません。新規ノート・レコードの提案には、読み取りと提案を許可したスペース全体のアクセスに、別途作成権限が必要です。特定オブジェクトのアクセス権では新規作成できません。エージェントには、本人の直接保存や提案を適用する権限はありません。

設定に含まれるトークンは発行時に一度だけ表示され、AgentSpace にはハッシュを保存します。表示中にコピーしてください。紛失したら権限を取り消し、新しく作成します。アクセス操作の結果が未確定の場合はフォームがロックされ、元の要求の再試行で解決します。同じスペースを開いたまま設定を往復しても、取得済みの一度限りの設定は保持されます。

エージェントは権限の範囲で資料を発見、絞り込み、検索し、制限付きの関連探索や特定版の読み取りを組み合わせられます。検索は範囲や制限を示し、意味的な網羅性を保証しません。「準備したコンテキスト」はツール結果にまとめた参照と範囲を記録します。ホストの受信、モデルの理解、作業完了を証明するものではありません。

## 提案を確認し、変更をたどる

**レビュー → 未処理**で提案を開きます。

1. 目的、理由、対象、基準版、差分全体を読みます。出典は引用された版で開けます。戻ると提案の選択と読む位置を保ちます。
2. 更新の提案は**変更案を適用**、新規作成の提案は**ノートを作成**または**レコードを作成**で反映します。**変更案を却下**しても正式な内容は変わりません。
3. 新規作成の提案では**新しい資料の下書き**から同じ種類の下書きを始められます。更新の提案では現在の内容を直接編集します。元の提案は別に残ります。

読んだだけでは提案は処理されません。既読・未読、未処理・適用済み・却下・競合、知識の確認状態は別です。基準版が進んでいると、その提案は適用できず、提案と現在の内容を両方保持します。**変更案の内容をコピー**して現在の内容を編集するか、エージェントに新しい提案を依頼できます。元のアクセス権を取り消した後でも、古い候補を却下できます。

**レビュー → 処理済み**では適用・却下した提案を確認できます。**適用時の版を読む**は適用時に保存した結果を開き、現在の原文は別の操作で開きます。却下した提案にも理由、差分、出典が残ります。

**アクティビティ → 実際の変更**には、保存や提案への決定が時刻・実行者とともに残り、当時の版や元の提案を開けます。適用した説明と出典は、別の許可済みエージェントも元のチャットなしでたどれます。結果を読めることは、その出典を読む権限を意味しません。

**履歴**で**元に戻す内容を確認**してから取り消します。後の編集がある場合は上書きを拒否します。旧版を読んだり、その版から新しいノートを作ったりすることもできます。

## 確認した知識に印を付ける

**詳細 → 版の確認**で、現在の保存済みの版と、最後に人が確認した版を比べます。保存済みの現在版を確かめてから**確認済みにする**を選びます。未保存の編集は別に保持されます。

ライブラリの**確認状態**で、**未確認**、**現在の版を確認済み**、**確認後に変更あり**を探せます。未確認は警告ではありません。取り込み、保存、閲覧、提案の適用で知識が自動的に確認済みになることはありません。印はその版を人が確認した記録であり、真実の保証や知識の自動更新ではありません。

## アーカイブする・外部アセットを再接続する

**詳細 → 資料をアーカイブ**は、ID と履歴を残して活動中の表示から外します。**アーカイブから戻す**で再び有効にできます。プロジェクトをアーカイブしても、そのノートや共有アセットをアーカイブ・削除しません。

外部アセットが移動したら、**アセットの場所を選択**で元と新しい場所を確認します。ID と履歴は保持され、外部ファイル自体は移動しません。通常の取り消しでは場所の変更を戻せません。元の場所に戻す場合は、その場所を明示的に選んでください。

## バックアップ・書き出し・復元

スペースメニューから**バックアップ・書き出し・復元**を開きます。

| 選択                 | 用途                           | 含むもの                                                             |
| -------------------- | ------------------------------ | -------------------------------------------------------------------- |
| 全体バックアップ     | 履歴とともにスペースを復元する | 一貫したデータベース、保持版、提案、操作履歴、下書き、取り込みの進捗 |
| 読み取り用の書き出し | 他のツールで現在の内容を読む   | アーカイブを含む現行の確定内容、型付きフィールド、関連、出所情報     |

読み取り用の書き出しは、旧版本文、提案、復旧用の下書きを含まず、全履歴の復元には使えません。過去の引用が書き出しにない本文を指す場合もあります。どちらも外部ファイルやリポジトリの実体はコピーせず、元のパスなど個人情報を含む場合があります。

**完了・検証済み**を待ってから成功を確認してください。応答を失った場合は結果不明なので、元の操作を確認・再試行します。完了した復元先を開けない場合は、開く操作を別途再試行します。検証済みの復元結果が取り消されたわけではありません。

バックアップは**新しい保存先**へ復元します。新しいインスタンス ID を持ち、復元先の古いエージェント権限は無効になります。元のスペースとアクセス権は変わりません。エージェントを明示的に再接続してください。別のインストールの下書きは復旧機能で探し、選んだ内容を新しいローカル下書きにコピーできます。元の下書きは保持されます。

## プライバシー・制限・詳しい説明

AgentSpace 自体はローカルデータを暗号化しません。OS の機能でスペースとコピーを保護してください。接続したエージェントは許可された資料を取得し、ホストの設定に従ってモデル提供元へ送る場合があります。ローカル保存はその送信を防ぎません。権限の取り消しは以後のツールアクセスを止めますが、すでに渡した資料は回収できません。

管理対象オブジェクトは 1 MiB、履歴を含むデータベースは 512 MiB までです。取り込みは深さ 12、訪問 1,000 件、選択テキスト 50 MiB などの制限があります。文脈ツールも件数・バイト数を制限します。上限に達したスペースも、書き込み可能な保存先へバックアップ・書き出しできます。

[製品の範囲](../PRD.md)、[ローカルデータと復元](../LOCAL_DATA.md)、[信頼の境界](../SECURITY.md)をご覧ください。現在の対象は macOS Apple Silicon です。[デスクトップ設定](../DESKTOP.md)と[検証](../TESTING.md)に、署名、対応環境、入力方式の検証範囲をまとめています。
