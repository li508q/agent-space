# 使用 AgentSpace

[English](en.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md)

AgentSpace 把写作、项目资料和 Agent 提案放在同一个本地空间。无需模型账号，也能阅读、编辑、组织和恢复工作。

## 创建或打开空间

选择**创建空间**，在新的本地文件夹建立空间；选择**打开空间**，打开已有 AgentSpace 文件夹；或先**打开示例空间**，试用与个人资料分开保存的合成内容。顶部会显示当前空间。

应用与空间彼此独立，移动应用不会移动数据。请把应用放到准备使用的位置，再生成 Agent 配置；可执行文件移动后需要重新生成配置。

在**设置**中选择界面语言和文字大小。切换语言不会翻译自己写的标题、正文和字段名称。

## 接着工作，或查找资料

**继续工作**提供恢复草稿、本空间实例中最近的最多十项资料，以及**查看最近变化**入口。最近列表指向同一份资料，不存文档副本；移除不可用的最近项不会删除资料。临时错误可以重试，恢复出的新实例有自己的最近列表。

在**资料库**中浏览、搜索和筛选已保存资料，或选择**新建资料**。没有最近工作不代表空间为空。已加载数量和分页结果只说明已检查范围，可继续加载更多。

## 导入已有资料

从继续工作、空间菜单，或无筛选的空资料库视图，打开**导入已有资料**。

1. 选择文件或文件夹。
2. 检查预览中的文本副本、项目分组、外部引用、跳过项和扫描限制。
3. 确认选择，再检查各项导入结果。

有效 UTF-8 Markdown 和纯文本会成为带来源信息的可编辑托管副本，原件保持不变。仓库与其他原生格式可以明确选择为外部引用，其内容不会被复制、执行或同步。知识区、项目区、HANDOFF 和仓库区的识别配置用于建议分组，可以不采用。

有限预览只覆盖报告的扫描范围。预览后来源变化，需要重新查看并确认。导入按项提交，部分失败时成功项仍会保留。重试或再次导入同一来源版本会复用原对象，保留之后的人工修改和现有关联。新分组只作用于新副本；需要调整复用对象时，请明确编辑其关系。不同来源版本会形成独立副本。

没有后台文件同步。重启后需明确继续未完成导入；恢复空间后，旧导入来源需要重新选择并确认。

## 写作与保存

通过**新建资料**创建独立笔记、项目、记录或可复用资产。笔记不必属于项目。在**详情**中编辑字段与关系，同一笔记或资产可以供多个项目引用，无需复制。

人工编辑在停止输入片刻后直接保存，也可以选择**立即保存**。留意编辑器旁的状态：

- **已保存**表示当前显示的编辑已保存为正式内容。
- **恢复草稿已保留**表示草稿已单独保留，不等于正文保存成功。
- **未保存**或**正在核对保存结果…**需要处理。保留编辑器，并使用提供的重试入口确认原请求。

发生冲突时，你的编辑与较新的保存版本分别保留。先查看当前原文，再决定如何继续。若草稿也无法保留，**复制编辑内容**可复制正文，便于关闭前另行保存。保留的草稿可从继续工作中恢复；恢复草稿本身不会把内容变成正式版本。

记录支持文本、有限数值、布尔、日期和单选。未设置（`null`）、空文本、`0` 和 `false` 彼此不同。修改字段名称会保留其身份，修改类型会清空值。复用字段定义会创建值未设置的新记录，不复制正文或关联。记录表是同一批记录的有界视图，列采用所选参考记录的字段定义。

## 查看项目积累和引用来源

项目概览显示目标摘录、接续引用、直接资产引用和分页资料。选择**编辑项目正文**可编辑全文；空项目可用**编辑项目目标**。数量表示已加载资料或已记录引用。字段和接续链接可以按需使用，不要求固定工作流程。

关系可以**跟随当前版本**，也可以指向**固定版本**。来源引用保留确切的保存版本，原文更新后也不改变。历史项目的链接与今天的项目资料分别呈现，不构成当时全部关联资料的完整快照。

在来源阅读器中选择**编辑当前原文**，打开同一托管对象的当前版本。例如，阅读第 1 版时编辑当前第 2 版，会保存为同一对象的第 3 版，第 1 版及其引用仍保持不变。已有未保存编辑保留在原编辑器，沿用原基础版本并显示冲突。**返回阅读**恢复引用版本与之前的位置。当前原文归档或不可用，不会移除仍可阅读的历史。这里编辑的是托管副本，不是外部原文件。

## 为 Agent 准备上下文

在已保存文档或来源阅读器中选择**准备上下文**。

1. 按需填写简短任务，最多 1,000 个 Unicode 码点。
2. 选择最多 **20 个不重复的保存版本引用**。默认选中起点资料；候选来自该版本的直接链接，以及起点为项目时的当前活动项目资料，可在各组继续加载。
3. 打开**检查说明与引用**，确认可见内容，再**复制说明与引用**。

说明包含任务和固定版本引用；选中起点项目时，可附最多 280 字符的目标摘录。取消该项目选择会同时移除其标题与摘录，不会递归带入链接文档的正文。不可用的已选版本需要重试或移除，不会替换为新版。

复制成功表示文字已进入剪贴板，不会创建授权，也不确认 Agent 已接收。准备内容在当前空间打开期间保留于内存，往返设置或导入后仍在；它不是已保存文档，也不是重启后可恢复的草稿。

## 明确授权，再连接 Agent

从上下文准备中选择**设置 Agent 接入**，或在**设置**中打开这个区域。

1. 填写授权名称，选择指定对象或整个空间，并选择读取与提案能力。
2. 检查选择，包括第一页以外的已准备资料。已有表单选择会保留；**使用所选资料**会明确替换它们。
3. 点击**创建接入授权**，复制 Codex 配置或 stdio 启动 JSON，加入宿主的 MCP 设置并重新连接，再把说明交给 Agent。[协议指南](../AGENT_PROTOCOL.md)也介绍 CLI 用法。

说明固定特定版本，对象授权则涵盖该对象的可读版本，**包括未来版本**。新增链接或项目资料不会把对象加入固定授权选集。允许新建笔记或记录，需要在具备读取和提案能力的整空间授权上单独启用创建权限；指定对象授权不能创建新对象。Agent 不获得你的直接保存或采纳提案权限。

配置包含只在签发时显示一次的令牌，AgentSpace 仅保存其哈希。请在可用时复制；丢失后撤销该授权并重新创建。授权操作结果未定时，表单保持锁定，需用原请求重试确认。同一打开空间中普通的设置往返会保留已知的一次性配置。

Agent 可以在授权范围内发现资料、筛选、搜索、有限探索关系，并读取确切版本。搜索会报告范围与限制，不保证语义上的全面召回。“准备的上下文”记录为工具结果整理的引用与区段，不代表宿主已接收、模型已理解或任务已完成。

## 审阅提案，回看变化

打开**审阅 → 待处理**，检查提案。

1. 阅读目的、理由、目标、基础版本与完整差异。按引用版本打开来源，返回时保留提案选择和阅读位置。
2. 更新提案选择**采纳提案**；创建提案选择**新建笔记**或**新建记录**。**拒绝提案**不会改变正式内容。
3. 创建提案可通过**新资料草稿**开始同类型的人工草稿；更新提案可打开当前对象直接编辑。原提案始终单独保留。

阅读不等于处理提案。已读／未读、待处理／已采纳／已拒绝／冲突，以及知识复核是不同状态。基础版本已经变化时，不能直接采纳，提案和当前内容都会保留。可**复制拟议内容**后编辑当前对象，或请 Agent 重新提案。原授权撤销后，仍可拒绝旧候选。

在**审阅 → 已处理**中查看已采纳或已拒绝提案。**阅读采纳时版本**打开采纳时保存的结果，当前原文有独立入口。拒绝后仍能查看原提案的理由、差异与来源。

**活动 → 实际变化**显示人工保存与提案决定，附时间、执行者及当时版本或原提案入口。采纳说明和来源引用可供另一个有权限的 Agent 追溯，无需原聊天；能读取结果不等于有权读取其来源。

在**历史**中先**预览撤销**。条件撤销会拒绝覆盖后来的编辑，也可以查看旧版或从该版创建新笔记。

## 标记自己复核过的知识

在**详情 → 版本复核**比较当前保存版本与最近人工复核版本。检查已保存的当前版本后，选择**标记为已复核**；未保存编辑独立保留。

资料库的**复核状态**可筛选**尚未复核**、**当前版本已复核**和**复核后有变化**。尚未复核是中性信息。导入、保存、阅读或采纳提案都不会自动标记知识已复核。标记仅记录人工复核过该版本，不认证真伪，也不会自动维护知识。

## 归档资料，或重连外部资产

用**详情 → 归档资料**让内容离开活动视图，身份与历史仍保留；用**从归档恢复**重新启用。归档项目不会归档或删除其笔记和共享资产。

外部资产移动后，用**重新选择资产位置**检查并确认新旧位置，对象身份和历史保持不变。重连不会移动外部文件，通用撤销也不回退位置变化；需要回到旧位置时，请明确选择该位置。

## 备份、导出与恢复

从空间菜单打开**备份、导出与恢复**。

| 选择       | 用途                     | 包含                                                   |
| ---------- | ------------------------ | ------------------------------------------------------ |
| 完整备份   | 连同历史恢复空间         | 一致的数据库、保留版本、提案、操作历史、草稿与导入进度 |
| 可阅读导出 | 在其他工具中阅读当前内容 | 当前正式内容（含归档）、结构化字段、关系与来源元数据   |

可阅读导出不含旧版正文、提案和恢复草稿，不能用于完整历史恢复；历史引用可能指向导出外的正文。两种方式都不复制外部文件或仓库，都可能包含来源路径等个人元数据。

等待**已完成并验证**再确认成功。响应丢失表示结果未知，应检查原操作或重试。已完成恢复但无法打开时，单独重试打开；这不取消已验证的恢复结果。

将备份恢复到**新的目标目录**。恢复副本获得新的实例身份，其中旧 Agent 授权停用；原空间及其授权保持不变。请明确重新连接 Agent。恢复功能可以发现其他安装留下的草稿，按选择复制为当前安装的新草稿，同时保留原稿。

## 隐私、限制与帮助

AgentSpace 不自行加密本地数据，请使用操作系统保护空间与副本。连接的 Agent 可以取得授权内容，其宿主可能按自身设置发送给模型服务商；本地保存不阻止这种传输。撤销授权会阻止后续工具访问，无法收回已经分享的资料。

托管对象完整内容上限 1 MiB；空间数据库（含历史）上限 512 MiB。导入包括深度 12、访问 1,000 项、所选文本 50 MiB 等限制。上下文工具另有结果数与字节限制。空间达到上限后，仍可向可写位置备份或导出。

参阅[产品范围](../PRD.md)、[本地数据与恢复](../LOCAL_DATA.md)和[信任边界](../SECURITY.md)。当前桌面环境为 macOS Apple Silicon；[桌面设置](../DESKTOP.md)与[验证说明](../TESTING.md)集中说明签名、平台和输入法验证边界。
