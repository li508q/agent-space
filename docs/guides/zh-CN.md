# 使用 AgentSpace

[English](en.md) · [简体中文](zh-CN.md) · [日本語](ja.md) · [한국어](ko.md) · [Español](es.md)

AgentSpace 把你自己的工作和 Agent 的协助放在同一个本地空间。无需模型账号也能写作、组织和恢复资料。连接外部 Agent 后，它通过明确授权读取上下文、提交可审阅的提案。

## 创建或打开空间

在新的本地文件夹创建空间，或打开已有 AgentSpace 空间。顶部始终标明当前空间。示例空间单独存放，并明确标为合成资料。

应用与数据彼此独立。移动应用不会移动空间。请把应用放到准备长期使用的位置，再生成 Agent 配置；可执行文件移动后需要重新生成配置。

首版验证平台为 macOS Apple Silicon。本地构建采用 ad-hoc 签名，没有 Developer ID 签名和公证；其他系统不作为已验证发行版。源码开发使用仓库指定的 Node 版本。

## 写作、项目与记录

“继续工作”用于恢复草稿、重新打开本空间实例中最近的最多十项资料，或“查看最近变化”。“资料库”保留完整的有界浏览；搜索、筛选和“新资料”位于同一滚动列表。最近位置只存 ID 与时间，不存文档副本。不可用的最近项可从列表移除，临时错误可重试；恢复出的新实例使用自己的最近列表。

资料库的“复核状态”可选全部、“尚未复核”“当前版本已复核”和“复核后有变化”。尚未复核是中性信息。详情中的“版本复核”明确列出当前保存版本与最近人工复核版本，未保存草稿另行保留。只能标记刚确认的已保存当前版本；保存或采纳提案不会自动复核，也不认证真伪。后续保存新版本后，可通过“复核后有变化”找到它。旧来源仍显示固定版本内容。

随时创建独立笔记。项目通过关系组织内容；同一篇笔记可以属于多个项目，资产也可以被多个项目引用，不必复制。

停止输入片刻后自动保存，也可以立即保存。“已保存”表示当前这一代编辑已持久保存；“已保留草稿”是另一种状态。遇到冲突或失败，使用重试、草稿或复制内容入口；后来的人工版本不会被静默覆盖。

打开项目先看概览：正文摘录、接续引用、直接资产引用和分页资料。分区入口位于全文之外。选择“编辑项目正文”写作，空项目可直接“编辑项目目标”。数量说明已加载项或已记录引用，不代表整个空间的总量。结构化字段与接续引用不要求固定工作流。

在来源阅读器中选择“编辑当前原文”，经过保存或草稿保护后打开同一个内部对象的当前版本。阅读 K1、编辑当前 K2，会保存为同 ID 的 K3，K1 与旧引用保持不变。同对象已有的未保存编辑继续保留在原编辑器，显示原基础版本和冲突。“返回阅读”恢复引用版本及调用位置。当前原文已归档或不可读时，仍保留可读历史。这里修改托管对象，不会编辑外部原文件。

记录支持文本、有限数值、布尔、日期和单选。字段名称可使用任何语言，改名保留稳定字段键。未填写、空文本、零与 false 是不同值。复用字段定义会新建一个值为空的记录。表格是这些记录的有限视图，不是独立的全局表结构。

关系区分“当前对象”和“指定版本的证据”。来源更新后，旧引用仍指向当时的版本。人工核阅标记也属于指定版本；保存或采纳不等于知识已经被证明正确。

## 导入已有目录

可从继续工作、无筛选的空资料库视图或空间菜单选择**导入已有资料**。“没有最近工作”表示尚无位置记录，不代表整个空间无资料。

通过原生选择器选择文件或文件夹，检查预览中的文本副本、项目分组与外部引用，再确认。知识区、项目区、HANDOFF 和仓库区的识别只是一种便捷配置，不是强制目录结构。

有效 UTF-8 Markdown、纯文本导入为可编辑副本，原文件保持不变。仓库与不支持的格式可以明确选择为外部引用；不会复制、运行或同步其中的内容。导入知识不会自动标记为已核阅。

留意扫描范围、跳过原因与截断提示。预览未展示的部分不代表已检查。预览后源文件变化，需要重新查看并确认。导入按项提交，部分成功会保留；重试能找到已提交的原始版本，不覆盖之后的人工修订。不同来源版本会形成新的副本。

分组选择只作用于新建副本。已经导入的同一来源版本会复用原对象，保留现有关联；这次导入不会重新分组。需要调整时，打开该对象明确修改关系。

没有后台双向文件同步。重启后显式继续；恢复副本中的旧导入必须重新选择来源、重新确认。

## 连接 Agent，检查变化

在已保存文档或来源阅读器中选择**准备上下文**，填写可选的简短任务（最多 1,000 个 Unicode 字符（码点）），选择最多 20 个保存版本。默认只选起点资料；此版本的直接链接与项目当前关联的活动资料分开显示，可点“加载更多”分段载入。历史项目不代表当时全部成员的完整快照。所选项目可附最多 280 字符的目标摘录，取消项目选择也会移除说明中的项目标题与摘录。

先**检查说明与引用**，再**复制说明与引用**。不可用的已选版本需要重试或移除，不会静默换成新版。复制成功仅表示进入剪贴板。准备稿在当前空间打开期间保留于内存，往返设置或导入仍会保留；它尚未保存为文档，也不是可在重启后恢复的人稿。

**设置 Agent 接入**把所选对象带入既有表单，第一页以外的对象也能检查与取消。只有明确点击**创建接入授权**才创建授权。已有选择不会被覆盖，可用**使用所选资料**明确替换。对象授权涵盖其可读版本，包括后续版本，而说明里的引用固定特定版本。访问操作结果未定时表单暂停修改，仍可用原请求重试；当前空间中往返设置会保留已知的一次性配置。

在设置的 Agent 访问区域创建带名称的授权。选择整个空间或指定对象、读取和提案能力；只有整空间且允许读取与提案的授权，才可以额外启用新建笔记或记录；指定对象授权不能新建对象。关系链接不会自动扩大权限。

复制生成的 MCP 配置到自己的宿主，或使用 [CLI](../AGENT_PROTOCOL.md)。令牌只在签发时返回一次，数据库只保留哈希；丢失后撤销并重新签发。配置包含访问凭证，应有意识地保管与分享。

Agent 可组合模型说明、结构化筛选、字面搜索、有限关系探索和精确版本读取。月度复盘只是一个可能的任务，不是内置工作流。搜索会报告范围与限制，不保证语义上的全面召回。

可以检查并复制已保存版本及其引用。未保存文字仍是草稿。

- **活动 → 实际变化**：重开后找回人工保存和提案决定。每条记录显示时间、执行者，并可打开当时版本或原提案。
- **准备的上下文**：检查为工具结果准备的引用与区段。准备完成不代表宿主已接收、理解或完成外部任务。
- **审阅 → 待处理／已处理**：按状态查看已载记录，继续加载或重试；检查原差异、理由和固定来源。**阅读采纳时版本**打开已保存结果，当前原文有单独入口。读完来源返回时，保留原提案选择与阅读位置。

创建或拒绝提案时，已采纳正文保持原样；被拒绝的建议仍可查看。

提案展示目的、理由、差异、预期基础版本与来源。打开来源时读取引用的原版，再回到审阅。采纳前，正式内容不变。基础版本改变时保留双方内容；旧授权被撤销后，你仍可拒绝其候选。条件撤销会保护后续工作；也可以查看旧版并复制为新笔记。

采纳时的说明与证据会进入历史。另一个有权限的 Agent 可以继续追溯，无需原 Agent 的私聊或操作密钥；能读结果不意味着能读所有证据。

## 归档、备份与恢复

归档让内容离开活动视图，不删除身份或历史。归档项目不会删除笔记和共享资产。恢复重新启用保留的当前内容。外部资产移动后，显式重选位置并检查前后路径；其对象身份和历史保持不变。通用撤销不回退外部位置重选；需要回到旧位置时，请明确重选该位置。

| 方式       | 包含                                                   | 不包含                               |
| ---------- | ------------------------------------------------------ | ------------------------------------ |
| 完整备份   | 一致的数据库、所有保留版本、提案、回执、草稿和导入进度 | 外部原文件与仓库内容                 |
| 可阅读导出 | 当前正式内容（含归档）、字段、关系及来源元数据         | 旧版正文、提案、回执、草稿与外部文件 |

导出是资料交换，不是完整历史恢复。两种副本都可能包含来源路径等个人元数据。等到明确校验完成才算成功；响应丢失表示结果未知，应查看状态或重试原操作。

备份恢复到新的目录，使用新的实例身份，停用恢复副本里的旧 Agent 授权。原空间及其权限不变。需要重新连接 Agent。其他安装留下的草稿可以查看并明确复制为当前安装的新草稿，原草稿保持不动。

## 当前边界

单对象完整内容上限 1 MiB；空间数据库（含历史、回执）上限 512 MiB。导入扫描深度 12、最多 1,000 个访问项、最多检查 50 MiB 的所选文本。上下文工具另有明确字节与结果数限制。空间达到数据库上限后仍可向可写位置备份或导出。

AgentSpace 不自行加密数据，依赖操作系统保护本地文件。外部 Agent 的模型服务及其他权限由宿主管理。云同步、团队账号、语义真伪判断、任意应用执行和完整电子表格引擎不在本次范围。首个公开版本使用格式 2；不支持的开发格式会原样拒绝，不在原文件上迁移。
